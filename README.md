# my-neuro-plugin-mcp-filesystem · 文件系统工具插件

> [my-neuro(肥牛)](https://github.com/morettt/my-neuro) 社区插件发布仓库 · 依赖已随仓库附带 · 无需 API Key
> 基于 [MCP Filesystem Server](https://github.com/modelcontextprotocol/servers/tree/main/src/filesystem) 改造 · 当前版本：1.0.1

给肥牛一双"翻文件的手"：它可以**读文件、写文件、编辑文件、浏览目录、按通配符搜索文件**——你让它"看看 D 盘项目里有哪些文档""帮我把这份配置里的端口改成 8080"，它就能直接在你的文件夹里干活。

## 这是什么？（给完全没接触过的小白）

- **插件**：给肥牛加功能的"扩展包"，放进插件文件夹、重启一次就生效
- **文件系统操作**：就是普通人在资源管理器里做的事——打开文件夹、看文件、改文件。装上本插件，AI 也能替你做这些事
- **安全边界**：AI 不是想碰哪就碰哪。你必须在配置里**明确指定允许它访问哪些文件夹**，没指定的地方它一步都进不去；而且默认**只能读不能写**，想让它能改文件要手动开"启用写操作"开关

## 功能特性

- **12 个文件工具**：读文件（支持只读前/后 N 行）、批量读、列目录（含大小）、目录树、搜索、查文件信息、写文件、查找替换编辑（支持 dryRun 预览）、建目录、移动/重命名
- **目录白名单**：所有操作严格限制在你允许的目录内，符号链接目标也必须在内
- **写操作默认关闭**：手动开启后 AI 才能创建/修改/移动文件，只读模式零风险
- **大文件保护**：超过大小上限（默认 512KB）的文件拒绝读取，防止撑爆 AI 的上下文
- **编码兼容**：配置自动处理 UTF-8 BOM，避免部分环境下解析报错

## 环境要求

- my-neuro（live-2d 桌宠）近期版本
- npm 依赖（minimatch）已随仓库 `node_modules` 附带，**一般无需再执行 npm install**；若你自行删改过，在本插件目录执行 `npm install --omit=dev` 重装

## 安装教程

**方式一（推荐）：WebUI 插件广场一键安装**

1. 打开 my-neuro 的 WebUI 控制面板 → 「广场」→ 插件广场
2. 找到本插件，点击安装（已装过则点更新）
3. 重启 Live2D 桌宠

**方式二：手动安装**

1. 点击本页绿色 `Code` 按钮 → `Download ZIP` 下载并解压
2. 把解压出的文件夹放入（确保 `index.js` 直接位于该目录下，不要多套一层）：

   `my-neuro/live-2d/plugins/community/mcp-filesystem/`

3. 重启 Live2D 桌宠，在 WebUI「插件管理」中启用

## 配置教程（逐项讲解）

| 配置项 | 填什么 | 不填会怎样 |
|--------|--------|-----------|
| **允许访问的目录**（关键） | 允许 AI 访问的文件夹路径，多个用英文逗号分隔，如 `D:\文档,K:\项目` | **留空则无法执行任何操作** |
| 启用写操作 | 开关：开了 AI 才能创建/修改/移动文件，默认关 | 关闭时 AI 只能读 |
| 最大读取文件大小（KB） | 超过此大小的文件拒绝读取，默认 512KB | 用默认 |
| 全局排除模式 | 搜索和目录树默认跳过的模式，默认 `node_modules,.git,.svn,__pycache__` | 用默认 |

> 提示：`plugin_config.json` 请保持 **UTF-8（无 BOM）** 编码（插件写入时会自动处理；my-neuro v643+ 主程序已含 BOM 修复，从 WebUI 保存配置更稳）。

**目录白名单怎么选**：只放你真想让 AI 碰的文件夹。比如只让它管你的笔记目录就只填笔记目录；千万别填 `C:\` 这种整个盘——等于把整个电脑都对它敞开。

## 使用教程（照着说就行）

配置好允许目录并重启后：

- 「看看 D:\文档 里都有什么文件」
- 「读一下 D:\文档\计划.txt 的最后 20 行」
- 「在 D:\项目 里搜一下所有 .md 文件」（需先开写操作的部分如下）
- 「新建一个 D:\文档\购物清单.txt，写上牛奶和鸡蛋」
- 「把 D:\文档\草稿.txt 里所有的'明天'替换成'后天'，先预览别真改」（dryRun）

## 常见问题（FAQ）

- **AI 说没有权限访问某目录？** 该目录不在「允许访问的目录」里，把它加进配置（逗号分隔）并重启。
- **AI 能读但改不了文件？** 正常，写操作默认关闭；到插件配置里打开「启用写操作」再重启。
- **读大文件报错？** 超过了大小上限（默认 512KB）。可以让 AI 用"只读前 N 行"的方式看，或按需调大上限（调太大可能撑爆上下文）。
- **会误删我的文件吗？** 本插件没有删除文件的工具（只有移动/重命名），且写操作默认关闭；开启后也只限于白名单目录内操作。
- **符号链接算在白名单里吗？** 链接指向的真实目标也必须在允许目录内，否则拒绝访问。

## 故障排查

1. 日志搜 `fs_` 或 `filesystem`，可看到每次文件操作的记录与拒绝原因
2. 操作全被拒绝时，先检查「允许访问的目录」是否填了、路径写法是否正确（Windows 路径反斜杠）
3. 还有问题请到 [本仓库 Issues](https://github.com/A-night-owl-Rabbit/my-neuro-plugin-mcp-filesystem/issues) 提问

## 更新与卸载

- **更新**：插件广场点更新，或手动覆盖 `community/mcp-filesystem/` 后重启
- **卸载**：WebUI「插件管理」停用并删除 `live-2d/plugins/community/mcp-filesystem/` 文件夹即可
